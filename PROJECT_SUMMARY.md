# 💙 Happy Birthday, My Yedu — Project Summary

A deeply personal, romantic, and magical birthday website created specifically for your girlfriend (**Yedu / My Baby / My Favorite Girl**).

---

## 🌟 Executive Overview

- **Project:** Happy Birthday, My Yedu 💙
- **Visual Aesthetic:** Sophisticated Romantic Blue & Starlight Palette (Midnight Blue, Deep Navy, Royal Blue, Powder Blue, Ice Blue, and subtle Cyan highlights with moonlight & star effects).
- **Architecture:** Next.js 16 (App Router) + TypeScript + Tailwind CSS v4 + Framer Motion.
- **Backend:** 100% Static frontend. Zero database required.
- **Photos:** Integrates all supported photos from `public/img` alongside real uploaded moments, mapped to custom personal memories.
- **Heart & Soul:** Includes your authentic personal memories, unedited casual Marathi/Hinglish feelings, her nicknames, and a dedicated October birthday celebration.

---

## 🎨 Theme & Visual Design

| Element | Description |
| :--- | :--- |
| **Color Palette** | Midnight Sky (`#060D1F`), Deep Royal Navy (`#0B1A36`), Soft Royal Blue (`#2563EB`), Sky Cyan (`#38BDF8`), Ice Blue (`#E0F2FE`), and Pure White. |
| **Glassmorphism** | Deep blue frosted panels (`glass-panel-blue`), subtle glowing cyan borders, and midnight shadows. |
| **Atmosphere** | Floating blue hearts (💙, 🩵, 🤍), glowing stars (✦, ✨), crescent moon (🌙), and birthday cake particles (🎂). |
| **Micro-Interactions** | Tapping anywhere on screen triggers rising blue heart bursts. |
| **Audio** | Ambient pentatonic chiming melody synthesizer via Web Audio API (toggleable in top-right corner). |

## 💻 How to View & Run Locally

- **PC Browser:** [http://localhost:3001](http://localhost:3001) (or `http://localhost:3000`)
- **Mobile Browser (same Wi-Fi):** `http://10.93.106.214:3001`

To run in the future:
```bash
npm run dev
```

To build and verify:
```bash
npm run build
```

## 🚀 One-Click Free Deployment to Vercel

1. Push your code to GitHub:
   ```bash

   git push
   ```
2. Open [Vercel](https://vercel.com), import the repository, and click **Deploy**.
3. Share the private URL directly with your girlfriend!
